Privacy · effective 28 August 2026

Your bird evidence stays on your device

There is no account, advertising, analytics, remote database, or media upload.

Records stored in your browser

Records, coordinates, photos, and audio use this browser’s private storage. Demo records use a separate demo database.

Your data leaves only through a file you choose to export. Deleting site data also deletes records without an exported backup.

Location choices in every export

Location access starts only after you press “Use my current location.” Region-only is the default.

Coordinates are rounded to the precision you choose. Exact coordinates need a separate warning acknowledgement.

Default previews and exports replace common coordinate formats found in names and notes.

Evidence prepared for JSON

JSON exports remove known location-bearing containers from JPEG, PNG, WebP, MP3, and WAV files. PDF exports include file names only.

Always check the visible preview and the files you share. The app cannot judge every kind of hidden or visual location clue.

Network use

The app contacts only its own site to load files and check for updates. Bird evidence is never sent with those requests.

Questions

Use the project repository for questions. Never post a sensitive nest location in a public issue.
